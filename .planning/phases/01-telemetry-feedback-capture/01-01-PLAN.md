<objective>
Build the opt-in, local-only telemetry core in `internal/telemetry` plus the `platform.TelemetryDir()` path helper and the `telemetry.enabled` config field. This is the foundation every Phase 1 command and the route-flow wiring depends on. Pure Go, stdlib only, no new module dependencies, and no `net`/`net/http` anywhere in the package.

Purpose: A measurable router needs a capture layer that is invisible when disabled (default) and never able to break routing when enabled. Satisfies REQ-01 (opt-in/local-only/no-network/non-fatal writes) and the data-model half of REQ-02 (decision records, feedback labels, promote into the golden set).

Output: `internal/telemetry` package (types + gate + writers + promote + disabled-notice), `platform.TelemetryDir()`, and the `telemetry.enabled` config field — all with failing-tests-first coverage for every behavior in CONTEXT.md `<specifics>`.
</objective>
