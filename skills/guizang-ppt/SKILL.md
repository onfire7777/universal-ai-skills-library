# Guizang PPT

Use this skill when the user needs a polished horizontal HTML presentation with editorial pacing, e-ink restraint, strong typographic hierarchy, and keyboard navigation.

## Workflow

1. Clarify the audience, talk length, slide count, and primary takeaway.
2. Choose an editorial structure: cover, thesis, context, evidence, framework, examples, implications, and close.
3. Use dense but readable layouts with clear section breaks, restrained color, strong contrast, and enough white space.
4. Build a single HTML file with keyboard navigation, responsive slide sizing, semantic text, and print-friendly fallbacks.
5. Verify slide rhythm, text fit, navigation behavior, and visual hierarchy before delivery.

## Output

Return concise English implementation notes plus the generated or modified HTML artifact path. Keep all visible presentation text in the requested language, defaulting to English.
