# Code Of Conduct

This project uses the Contributor Covenant Code of Conduct, version 2.1.

## Our Standards

Examples of behavior that contributes to a positive environment:

- being respectful and concrete in technical discussions
- accepting constructive feedback
- focusing criticism on ideas, code, and project outcomes
- helping maintain a safe, useful, public repository

Examples of unacceptable behavior:

- harassment, threats, or personal attacks
- publishing private information without permission
- posting secrets, tokens, or credentials
- intentionally disrupting the project or its users

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributions that
violate this code. Serious or repeated violations may result in a ban from
participating in the project.
